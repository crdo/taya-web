# Taya web

Landing page and privacy policy for Taya, a learning app for kids aged 5 to 10.

- `index.html`: landing page (Czech and English)
- `privacy/`: privacy policy linked from the App Store and Google Play

Static files only, served by GitHub Pages from the root of `main`. Store links go in `window.TAYA_STORES` at the top of `index.html`.
